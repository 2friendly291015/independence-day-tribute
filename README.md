# Independence Day Website

[![Live Website](https://img.shields.io/badge/Live_Website-Visit-success?style=for-the-badge)](https://independencedaywebpage2025.netlify.app/)

A tribute website for India's Independence Day, created on 15 August 2025. The project presents important moments from India's freedom movement with historical images and patriotic audio.

## Live Website

[https://independencedaywebpage2025.netlify.app/](https://independencedaywebpage2025.netlify.app/)

## Highlights

- Timeline-style Independence Day content
- Historical image assets for major freedom movement milestones
- Patriotic audio asset for a richer visitor experience
- Static website suitable for Netlify deployment
